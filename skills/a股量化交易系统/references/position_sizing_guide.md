# 凯利公式与仓位管理指南

> 在A股活下去的第一原则：不要亏大钱。凯利公式是理论最优，但A股需要特殊适配。

---

## 一、凯利公式基础

### 标准公式

```
f* = (bp - q) / b

f* : 最优仓位比例
b  : 盈亏比（平均盈利/平均亏损）
p  : 胜率
q  : 败率 = 1 - p
```

### 示例

| 策略 | 胜率p | 盈亏比b | 凯利仓位f* |
|:---|:---:|:---:|:---:|
| 龙头首阴 | 55% | 2.5 | (0.55×2.5 - 0.45)/2.5 = 37% |
| 均线多头 | 60% | 2.0 | (0.60×2.0 - 0.40)/2.0 = 40% |
| 箱体突破 | 45% | 4.0 | (0.45×4.0 - 0.55)/4.0 = 31% |
| 戴维斯双击 | 65% | 3.0 | (0.65×3.0 - 0.35)/3.0 = 53% |

## 二、A股适配修正

### 2.1 流动性约束

A股不同于理论假设，存在以下约束：

| 约束 | 处理方式 |
|:---|:---|
| 单票持仓上限 | 凯利结果 > 20% → 截断至20% |
| 总仓位上限 | 受五维择时限制，bull≤80%，bear≤20% |
| 现金保底 | 始终保留≥30%现金 |
| 涨跌停限制 | 无法即时止损，需提前设条件单 |
| T+1制度 | 当日买入无法卖出，隔夜风险需计入 |

### 2.2 半凯利原则

**核心原则**: A股波动大、黑天鹅多，使用**半凯利**（Half-Kelly）更稳健。

```
实际仓位 = 凯利仓位 × 0.5 × 趋势调整系数
```

| 市场环境 | 趋势调整系数 |
|:---:|:---:|
| bull | 1.0 |
| 震荡偏强 | 0.8 |
| 震荡 | 0.6 |
| 震荡偏弱 | 0.4 |
| bear | 0.2 |

### 2.3 等级倍率

根据四层框架评分调整:

| 评分等级 | 等级倍率 |
|:---:|:---:|
| S (85-100) | 1.2 |
| A (70-84) | 1.0 |
| B (55-69) | 0.7 |
| C (40-54) | 0.4 |
| D (<40) | 0（禁止买入）|

## 三、完整仓位计算公式

```python
def calculate_position(win_rate, profit_loss_ratio, market_env, score_grade, portfolio):
    """
    计算最优仓位
    
    Args:
        win_rate: 历史胜率 (0-1)
        profit_loss_ratio: 盈亏比
        market_env: 市场环境 (bull/震荡/bear)
        score_grade: 评分等级 (S/A/B/C/D)
        portfolio: 当前组合状态
    
    Returns:
        dict: 建议仓位及相关信息
    """
    # Step 1: 基础凯利
    kelly = (win_rate * profit_loss_ratio - (1 - win_rate)) / profit_loss_ratio
    kelly = max(0, min(1, kelly))  # 约束在0-100%
    
    # Step 2: 半凯利
    half_kelly = kelly * 0.5
    
    # Step 3: 趋势调整
    env_multiplier = {
        'bull': 1.0,
        '震荡偏强': 0.8,
        '震荡': 0.6,
        '震荡偏弱': 0.4,
        'bear': 0.2
    }
    adjusted = half_kelly * env_multiplier.get(market_env, 0.6)
    
    # Step 4: 等级倍率
    grade_multiplier = {
        'S': 1.2, 'A': 1.0, 'B': 0.7, 'C': 0.4, 'D': 0
    }
    final = adjusted * grade_multiplier.get(score_grade, 0)
    
    # Step 5: 硬性约束
    single_limit = 0.20  # 单票≤20%
    total_limit = {
        'bull': 0.80,
        '震荡偏强': 0.60,
        '震荡': 0.40,
        '震荡偏弱': 0.30,
        'bear': 0.20
    }
    cash_min = 0.30  # 现金≥30%
    
    position = min(final, single_limit)
    position = min(position, total_limit.get(market_env, 0.40))
    
    # 确保现金比例
    if portfolio['cash_ratio'] - position < cash_min:
        position = portfolio['cash_ratio'] - cash_min
    
    return {
        'kelly_raw': kelly,
        'half_kelly': half_kelly,
        'after_env': adjusted,
        'final_position': max(0, position),
        'cash_after': portfolio['cash_ratio'] - position,
        'risk_per_trade': position * 0.05  # 假设止损5%
    }
```

## 四、风险控制规则

### 4.1 单笔风险控制

| 规则 | 说明 |
|:---|:---|
| 单笔最大亏损 | ≤总资金2% |
| 止损幅度 | 短线-5%，波段-8%，长线-15% |
| 强制止损 | 触及止损价无条件执行，不犹豫 |
| 时间止损 | 买入后5日无表现，考虑出局 |

### 4.2 组合风险控制

| 规则 | 说明 |
|:---|:---|
| 行业集中度 | 单一行业≤40% |
| 风格集中度 | 成长/价值/周期，至少覆盖2种 |
| 市值分布 | 大盘/中盘/小盘，至少覆盖2种 |
| 策略分散 | 同时运行≤3种不同战法 |

### 4.3 极端情况处理

| 情况 | 操作 |
|:---|:---|
| 单票连续2日跌停 | 第3日集合竞价挂跌停价出逃 |
| 大盘单日暴跌>5% | 清仓或降至10%以下 |
| 持有的票被ST | 次日复牌立即挂单卖出 |
| 监管政策突变 | 相关板块全部清仓 |
| 黑天鹅事件 | 无条件降至最低仓位 |

## 五、仓位动态调整

### 5.1 盈利加仓

```
初始仓位: 10%
盈利+10% → 加仓至15%
盈利+20% → 加仓至20%（上限）
```

**条件**: 加仓点必须是新的入场信号，不能单纯因为涨了而加。

### 5.2 亏损减仓

```
初始仓位: 10%
亏损-5% → 止损清仓
亏损-3%但趋势走坏 → 减仓至5%
```

### 5.3 定期再平衡

每周五收盘后检查:
- 单票仓位因涨跌超出目标 ±5% → 再平衡
- 总仓位偏离择时建议 ±10% → 再平衡
- 现金低于30% → 减仓至达标
