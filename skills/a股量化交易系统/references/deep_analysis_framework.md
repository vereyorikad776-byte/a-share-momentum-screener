# 深度分析框架：15提示词7步法

> 对单只股票进行全面CT扫描，从基本面到技术面，从资金到情绪，无死角诊断。

---

## 七步法流程

```
Step 1: 公司画像
    ↓
Step 2: 财务透视
    ↓
Step 3: 行业地位
    ↓
Step 4: 资金行为
    ↓
Step 5: 技术形态
    ↓
Step 6: 催化因素
    ↓
Step 7: 风险评估
    ↓
输出: 综合诊断报告 + 交易建议
```

---

## Step 1: 公司画像（2提示词）

### 提示词1: 核心业务
```
分析{股票名称}的核心业务构成：
1. 主营业务是什么？占比多少？
2. 产品/服务面向哪些客户？
3. 商业模式是ToB还是ToC？
4. 收入来源是否集中？（前5大客户占比）
5. 是否有季节性特征？
```

### 提示词2: 发展历程
```
梳理{股票名称}的发展历程：
1. 公司成立时间，上市时间
2. 发展历程中的关键转折点
3. 近5年营收/利润增长轨迹
4. 管理层背景及稳定性
5. 股权结构（是否有实控人？股权是否分散？）
```

---

## Step 2: 财务透视（3提示词）

### 提示词3: 盈利能力
```
分析{股票名称}的盈利能力（近5年+最近季报）：
1. 毛利率变化趋势及原因
2. 净利率变化趋势及原因
3. ROE水平及杜邦分析拆解
4. 与行业平均水平对比
5. 盈利质量（经营现金流/净利润）
```

### 提示词4: 成长能力
```
分析{股票名称}的成长能力：
1. 近5年营收复合增长率
2. 近5年净利润复合增长率
3. 增长驱动力（量增/价涨/新业务？）
4. 订单/合同负债情况（未来收入前瞻）
5. 研发投入及转化效率
```

### 提示词5: 财务健康
```
分析{股票名称}的财务健康状况：
1. 资产负债率及变化
2. 有息负债规模及结构
3. 流动比率/速动比率
4. 应收账款周转天数
5. 存货周转天数
6. 自由现金流情况
7. 是否存在大存大贷等异常
```

---

## Step 3: 行业地位（2提示词）

### 提示词6: 行业分析
```
分析{股票名称}所在行业：
1. 行业规模及增速
2. 行业生命周期（导入/成长/成熟/衰退）
3. 行业竞争格局（CR5/CR10）
4. 行业进入壁垒
5. 行业周期性特征
6. 政策环境（支持/中性/限制）
```

### 提示词7: 竞争地位
```
分析{股票名称}的竞争地位：
1. 市场份额及变化趋势
2. 主要竞争对手及对比
3. 核心竞争力（品牌/技术/成本/渠道）
4. 护城河宽度及可持续性
5. 定价权强弱
```

---

## Step 4: 资金行为（2提示词）

### 提示词8: 主力资金
```
分析{股票名称}的主力资金动向（近1个月）：
1. 主力资金净流入/流出情况
2. 大单买卖比例
3. 龙虎榜数据（如有）
4. 机构调研频率
5. 机构持仓变化（季报数据）
```

### 提示词9: 北向资金
```
分析{股票名称}的北向资金动向：
1. 近1个月北向资金净流入/流出
2. 北向资金持股比例变化
3. 北向资金买卖特征（持续/间歇）
4. 与股价走势的关联性
```

---

## Step 5: 技术形态（2提示词）

### 提示词10: 趋势分析
```
分析{股票名称}的技术趋势：
1. 中长期趋势（周线/月线）
2. 短期趋势（日线）
3. 均线系统排列状态
4. 关键支撑位和压力位
5. 成交量趋势
```

### 提示词11: 形态与指标
```
分析{股票名称}的技术形态：
1. 当前处于什么形态（箱体/通道/三角形/头肩等）
2. MACD状态（金叉/死叉/背离）
3. KDJ位置（超买/超卖）
4. RSI强度
5. 布林带位置及开口方向
6. 近期关键K线形态（长阳线/十字星/锤子线等）
```

---

## Step 6: 催化因素（2提示词）

### 提示词12: 已知催化
```
梳理{股票名称}的已知催化因素：
1. 即将发布的财报/业绩预告
2. 已公告但尚未实施的重大事项（定增/重组/股权激励）
3. 行业政策变化预期
4. 产品发布/订单公告
5. 股东大会/解禁日等重要日期
```

### 提示词13: 潜在催化
```
分析{股票名称}的潜在催化因素：
1. 行业景气度变化预期
2. 竞争对手动态可能带来的影响
3. 宏观政策可能带来的利好/利空
4. 技术突破或产品迭代预期
5. 产业链上下游变化的影响
```

---

## Step 7: 风险评估（2提示词）

### 提示词14: 个股风险
```
评估{股票名称}的主要风险：
1. 业绩不及预期风险
2. 估值回调风险
3. 行业政策风险
4. 竞争格局恶化风险
5. 大股东减持/质押风险
6. 流动性风险（日均成交额）
7. 黑天鹅风险（诉讼/监管/天灾）
8. 汇率/原材料价格波动风险（如适用）
```

### 提示词15: 交易建议
```
基于以上分析，给出{股票名称}的交易建议：
1. 综合评级（强烈买入/买入/持有/减持/卖出）
2. 适合什么策略（过夜/波段/长线）
3. 建议仓位（占总资金比例）
4. 建议入场价位区间
5. 止损位设置
6. 目标价位
7. 关键跟踪指标（什么变化需要重新评估）
8. 最佳介入时机判断
```

## 输出格式

```markdown

## 综合评分: XX/100 | 评级: X级 | 策略: XXX

### 一、公司画像
[核心发现，3-5句话]

### 二、财务透视
- 盈利能力: X分（说明）
- 成长能力: X分（说明）
- 财务健康: X分（说明）

### 三、行业地位
- 行业前景: 看好/中性/谨慎
- 竞争地位: 龙头/前列/跟随

### 四、资金行为
- 主力资金: 流入/流出/中性
- 北向资金: 流入/流出/中性

### 五、技术形态
- 趋势: 上升/下降/震荡
- 关键位置: 支撑X / 压力X

### 六、催化因素
- 已知催化: [列表]
- 潜在催化: [列表]

### 七、风险评估
- 主要风险: [列表]
- 风险等级: 高/中/低

### 交易建议
- 评级: 强烈买入/买入/持有/减持/卖出
- 策略: 过夜/波段/长线
- 建议仓位: X%
- 入场区间: X - X
- 止损位: X (-X%)
- 目标位: X (+X%)
- 跟踪指标: [列表]
```
