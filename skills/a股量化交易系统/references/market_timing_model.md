# 五维择时模型

> 判断市场整体环境：bull（满仓干）/ 震荡（半仓玩）/ bear（空仓看）。

---

## 模型架构

```
五维择时
    ├─ 估值维度 (20%)
    ├─ 资金维度 (25%)
    ├─ 技术维度 (25%)
    ├─ 情绪维度 (20%)
    └─ 基本面维度 (10%)
    
输出: 综合评分 → bull/震荡/bear + 建议仓位
```

---

## 一、估值维度（20%）

### 1.1 全市场PE/PB分位

| 条件 | 得分 |
|:---|:---:|
| PE<历史20%分位 | 100分（极度低估）|
| PE<历史30%分位 | 80分（低估）|
| PE<历史50%分位 | 60分（合理偏低）|
| PE<历史70%分位 | 40分（合理偏高）|
| PE>历史80%分位 | 20分（高估）|

### 1.2 风险溢价（ERP）

```
ERP = 1/全市场PE - 10年期国债收益率
```

| 条件 | 得分 |
|:---|:---:|
| ERP>历史90%分位 | 100分 |
| ERP>历史70%分位 | 70分 |
| ERP>历史50%分位 | 50分 |
| ERP<历史30%分位 | 20分 |

## 综合评分与仓位建议

```
综合评分 = 估值×20% + 资金×25% + 技术×25% + 情绪×20% + 基本面×10%
```

| 综合评分 | 市场环境 | 建议仓位 | 策略偏好 |
|:---:|:---:|:---:|:---|
| >80 | bull | 70-80% | 趋势+突破，积极进攻 |
| 60-80 | 震荡偏强 | 50-60% | 回调低吸，结构行情 |
| 40-60 | 震荡 | 30-40% | 缩量回踩，严格止损 |
| 20-40 | 震荡偏弱 | 20-30% | 观望为主，偶尔游击 |
| <20 | bear | 0-20% | 空仓或极轻仓，只做空头策略 |

## 使用注意

1. **左侧信号**: 估值+情绪维度提前见底，但技术和资金可能仍向下
2. **右侧信号**: 技术和资金拐点确认，但估值和情绪可能已修复一段
3. **共振最佳**: 五维同时向好，大胆做多；五维同时向差，坚决空仓
4. **单一维度极端**: 如情绪维度<10分（极度恐慌），可能是短期反弹机会

---

*择时模型参数需根据A股历史数据回测校准，建议每年 review 一次*
