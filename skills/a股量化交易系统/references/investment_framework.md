# 投资框架与风控体系

> 20年A股实战经验的浓缩：什么时候该激进，什么时候该认怂，什么时候该空仓。

---

## 一、投资哲学

### 核心原则

1. **保本第一**: 单笔亏损≤总资金2%，单月亏损≤总资金10%
2. **顺势而为**: 大盘环境不好，个股再好也不做
3. **确定性优先**: 宁可错过，不可做错
4. **简单重复**: 只做熟悉的模式，不搞花样
5. **计划交易**: 盘前定计划，盘中只执行，不临时起意

### 市场认知

- A股是政策市+资金市，基本面只是配角
- 散户的优势是灵活，机构的优势是研究深度
- 不要和趋势作对，不要和监管作对
- 没有永远有效的策略，只有永远有效的纪律

## 二、市场环境应对

### 2.1 牛市（五维择时>80）

**特征**: 均线多头排列，成交量放大，涨停数>100，北向持续流入

**策略**:
- 仓位: 70-80%
- 主攻: 趋势策略（均线多头、量价齐升、箱体突破）
- 辅攻: 短线打板（龙头首阴、首启战法）
- 持仓: 5-8只，分散行业
- 止损: 放宽至-8%（趋势中正常回调）

**禁忌**:
- 不要过早下车（让利润奔跑）
- 不要频繁切换（牛市捂股）
- 不要做空（逆趋势）

### 2.2 震荡市（五维择时40-80）

**特征**: 指数横盘，板块快速轮动，成交量萎缩

**策略**:
- 仓位: 30-50%
- 主攻: 震荡策略（缩量回踩、箱体高抛低吸）
- 辅攻: 事件驱动（政策/业绩/重组）
- 持仓: 3-5只，快进快出
- 止损: 严格-5%

**禁忌**:
- 不要追高（轮动市追高必套）
- 不要死扛（震荡市没有趋势）
- 不要满仓（留现金等确定性机会）

### 2.3 熊市（五维择时<40）

**特征**: 均线空头排列，成交量低迷，涨停数<30

**策略**:
- 仓位: 0-20%
- 主攻: 空仓观望，或极轻仓游击
- 辅攻: 戴维斯双击（左侧布局，需耐心）
- 持仓: 0-2只，试盘性质
- 止损: 极严格-3%

**禁忌**:
- 不要抄底（熊市没有底）
- 不要补仓（越补越套）
- 不要幻想（接受亏损，保存实力）

## 三、交易纪律

### 3.1 入场纪律

| 规则 | 说明 |
|:---|:---|
| 环境过滤 | 五维择时<40，禁止开新仓 |
| 评分过滤 | 四层评分<55，禁止买入 |
| 消息过滤 | 监管函/业绩暴雷/大额减持，一票否决 |
| 计划过滤 | 非盘前计划内的标的，不临时买入 |
| 数量过滤 | 持仓已达8只，不再开新仓 |

### 3.2 持仓纪律

| 规则 | 说明 |
|:---|:---|
| 每日复盘 | 收盘后检查所有持仓的止损/止盈位 |
| 浮盈处理 | 浮盈>10%，止损位上移至成本价（保本）|
| 浮亏处理 | 浮亏>-3%，开始警惕；>-5%，评估是否提前止损 |
| 板块联动 | 持仓股所在板块集体走弱，考虑减仓 |
| 大盘变脸 | 大盘单日跌>3%，减仓至50%以下 |

### 3.3 出场纪律

| 规则 | 说明 |
|:---|:---|
| 止损出场 | 触及止损价，无条件卖出，不犹豫 |
| 止盈出场 | 达到目标价，分批减仓（不要一次性清仓）|
| 时间出场 | 买入后10日无表现，考虑换股 |
| 逻辑出场 | 买入逻辑被破坏（业绩不及预期/行业政策变化），立即卖出 |
| 环境出场 | 市场环境恶化，减仓或清仓 |

## 四、风控体系

### 4.1 三层风控

```
第一层: 单笔风控
    ├─ 单笔亏损≤总资金2%
    ├─ 单票仓位≤20%
    └─ 严格止损执行

第二层: 组合风控
    ├─ 行业分散≤40%
    ├─ 风格分散（成长/价值/周期）
    ├─ 策略分散≤3种
    └─ 总仓位跟随择时

第三层: 系统风控
    ├─ 月度亏损≥10% → 强制减仓至30%
    ├─ 连续3月亏损 → 暂停交易，复盘系统
    ├─ 黑天鹅事件 → 清仓观望
    └─ 年度回撤≥20% → 全面停手，重新评估
```

### 4.2 应急预案

| 场景 | 触发条件 | 操作 |
|:---|:---|:---|
| 个股闪崩 | 持仓股盘中跌>7% | 立即挂跌停价卖出 |
| 大盘暴跌 | 大盘单日跌>5% | 清仓或降至10% |
| 满仓套牢 | 总浮亏>15% | 砍掉 weakest 的50%仓位，保留现金 |
| 连续止损 | 连续5笔亏损 | 暂停1周，检查策略是否失效 |
| 政策突变 | 监管发布重大利空 | 相关板块全部清仓 |

## 五、心态管理

### 5.1 常见心态陷阱

| 陷阱 | 表现 | 对策 |
|:---|:---|:---|
| FOMO（怕错过）| 看到别人赚钱就冲动买入 | 写交易日志，回顾FOMO的亏损案例 |
| 报复性交易 | 亏损后加大仓位想翻本 | 设定单日最大亏损线，触及即停 |
| 锚定效应 | 成本价锚定决策 | 忘记成本，只看当下值不值得持有 |
| 确认偏误 | 只找支持自己观点的信息 | 强制列出买入的3个风险和卖出的3个理由 |
| 过度自信 | 连续盈利后加大杠杆 | 盈利提取20%出金，强制降低仓位 |

### 5.2 日常修炼

1. **盘前**: 看新闻、定计划、设条件单
2. **盘中**: 尽量少看盘，避免情绪干扰，执行计划
3. **盘后**: 复盘当日操作，记录交易日志
4. **周末**: 宏观经济 review，策略有效性检查
5. **月末**: 月度总结，盈亏分析，参数校准
