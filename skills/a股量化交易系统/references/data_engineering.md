# 数据工程与因子检验

> 从"规则驱动"升级到"数据驱动"的核心基础设施

---

## 为什么需要数据工程

**以前的问题**:
- PE=1000 的股票直接拉偏评分 → 极端值未处理
- 银行股天然PE低、科技股天然PE高 → 行业差异未剥离
- ROE 和 市值 量纲不同 → 直接相加不公平

**现在的方案**:

```
原始数据
    ↓
去极值 (MAD/3σ)
    ↓
中性化 (去除行业/市值影响)
    ↓
标准化 (Z-Score)
    ↓
干净的因子值
```

---

## 三步预处理

### Step 1: 去极值

**方法**: MAD（中位数绝对偏差）

```python
median = 数据的中位数
mad = |数据 - median| 的中位数
upper = median + 3 × 1.4826 × mad
lower = median - 3 × 1.4826 × mad

# 裁剪到 [lower, upper]
```

**为什么用 MAD 不用 3σ？**
- 3σ 受极端值影响大
- MAD 基于中位数，更稳健

### Step 2: 中性化

**方法**: 截面回归去残差

```python
factor = β0 + β1×行业_dummy + β2×log(市值) + ε

# 取残差 ε 作为中性化后的因子
# 这样 factor 就不包含行业和市值的信息了
```

**为什么要中性化？**
- 银行股PE天然低，不是真的"便宜"
- 小市值股票波动大，不是真的"高风险"
- 去掉这些混淆因素，因子才纯粹

### Step 3: 标准化

**方法**: Z-Score

```python
z = (factor - mean) / std

# 结果: 均值为0，标准差为1
# 不同因子可以公平比较和加权
```

## 因子检验

### 检验流程

```
原始因子值
    ↓
IC检验 (Pearson/Spearman)
    ↓
多空组合检验
    ↓
换手率检验
    ↓
t检验
    ↓
通过? → 纳入评分框架
```

### 核心指标

| 指标 | 说明 | 通过标准 |
|:---|:---|:---|
| **IC均值** | 因子与收益的相关系数 | \|IC\| > 0.03 |
| **IC_IR** | IC信息比率 | IC_IR > 0.5 |
| **Rank IC** | Spearman秩相关 | 与IC一致 |
| **换手率** | 因子稳定性 | < 50% |
| **t统计量** | 统计显著性 | \|t\| > 2 |
| **多空收益** | 顶层-底层收益差 | > 0 |

### 使用方式

```bash
# 因子检验模式
python3 scripts/master_controller.py --validate

# 输出示例:
# 因子    IC均值    IC_IR    正IC比例    换手率    多空收益    通过
# PE      0.052     0.82     58%         35%       12.5%       True
# ROE     0.038     0.61     55%         28%       8.3%        True
# PB      0.015     0.23     51%         42%       3.1%        False
```

## 分层回测

### 方法

将股票按评分分5层（S/A/B/C/D），检验各层收益是否单调递减：

```
S层（评分最高）→ 应该收益最高
A层 → 次之
B层 → 中等
C层 → 较差
D层（评分最低）→ 应该收益最低
```

### 检验标准

1. **收益单调性**: S > A > B > C > D
2. **Spearman相关**: 排名与收益秩相关 > 0.5
3. **多空组合**: S层 - D层收益 > 0，夏普 > 0.5

### 使用方式

```bash
# 分层回测模式
python3 scripts/master_controller.py --backtest

# 输出示例:
# S层: 平均收益=15.2%, 夏普=1.23
# A层: 平均收益=10.5%, 夏普=0.89
# B层: 平均收益=5.1%, 夏普=0.45
# C层: 平均收益=-2.3%, 夏普=-0.12
# D层: 平均收益=-8.7%, 夏普=-0.56
# 
# 单调性检验: 通过
# Spearman相关: 0.89
# S-D多空收益: 23.9%
```

## 与评分框架的关系

```
传统评分（拍脑袋）:
价值 30分 + 财务 20分 + 资金 25分 + 风控 25分
    ↓
凭什么价值占30%？

数据驱动评分（实证）:
PE因子:  IC=0.052, IC_IR=0.82 → 权重 25%
ROE因子: IC=0.038, IC_IR=0.61 → 权重 20%
资金因子: IC=0.065, IC_IR=1.12 → 权重 35%
风控因子: IC=0.028, IC_IR=0.45 → 权重 20%
    ↓
权重由IC_IR决定，有数据支撑
```

## 使用场景

### 场景1: 日常交易（实盘模式）
```bash
python3 scripts/master_controller.py 000001 600519
```
预处理在后台自动进行，不需要额外操作。

### 场景2: 因子研究（验证模式）
```bash
python3 scripts/master_controller.py --validate
```
检验当前因子有效性，决定哪些因子纳入评分。

### 场景3: 策略审计（回测模式）
```bash
python3 scripts/master_controller.py --backtest
```
验证评分体系是否真能区分好坏股票。
