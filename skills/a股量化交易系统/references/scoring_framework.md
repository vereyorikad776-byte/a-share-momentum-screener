# 四层框架评分细则

> 总分100分，基于20年A股实战经验权重分配。价值30/财务20/资金25/风控25。

---

## 一、价值猎手（30分）

**核心逻辑**: 在A股，估值是安全边际的底线，但不同行业适用不同估值方法。

### 1.1 PE-TTM分位（8分）

| 条件 | 得分 |
|:---|:---:|
| PE<历史10%分位 | 8分 |
| PE<历史20%分位 | 6分 |
| PE<历史30%分位 | 4分 |
| PE<历史50%分位 | 2分 |
| PE>历史80%分位 | 0分 |

**特殊处理**:
- 周期股（钢铁/煤炭/化工）: 使用PB替代PE
- 亏损股: 使用PS或市值/营收
- 银行股: PE<5倍满分，不考虑历史分位
- 成长股（增速>50%）: PEG<1.5满分

### 1.2 PEG（6分）

| PEG>2.0 | 0分 |

**注意**: 净利润增速使用最近2季度平均年化增速。

## 二、财务透视（20分）

**核心逻辑**: A股财务造假频发，财务评分重在质量而非单纯增长。

### 2.1 ROE（6分）

| 条件 | 得分 |
|:---|:---:|
| ROE>20%且连续3年 | 6分 |
| ROE>15%且连续2年 | 5分 |
| ROE>10% | 3分 |
| ROE<5% | 0分 |
| ROE波动>50%（不稳定）| -2分 |

**杜邦分析验证**:
- 高ROE来自高净利率: 优质（品牌/技术壁垒）
- 高ROE来自高周转: 尚可（零售/贸易）
- 高ROE来自高杠杆: 警惕（地产/金融）

### 2.2 营收增长（4分）

| 条件 | 得分 |
|:---|:---:|
| 增速>50% | 4分 |
| 增速>30% | 3分 |
| 增速>15% | 2分 |
| 增速>0% | 1分 |
| 增速<0% | 0分 |

**质量验证**: 营收增长但应收账款增速>营收增速 → 扣2分。

### 2.3 毛利率（4分）

| 条件 | 得分 |
|:---|:---:|
| 毛利率>50% | 4分 |
| 毛利率>30% | 3分 |
| 毛利率>20% | 2分 |
| 毛利率<10% | 0分 |

**趋势**: 毛利率连续2季度下滑 → 扣2分。

### 2.4 现金流质量（6分）

| 条件 | 得分 |
|:---|:---:|
| 经营现金流/净利润>1.2 | 6分 |
| 经营现金流/净利润>0.8 | 4分 |
| 经营现金流/净利润>0.5 | 2分 |
| 经营现金流为负 | 0分 |

**额外加分**: 自由现金流连续3年为正 +2分。

## 评分等级

| 总分 | 等级 | 操作建议 |
|:---:|:---:|:---|
| 85-100 | S | 重点关注，可重仓 |
| 70-84 | A | 优选标的，标准仓位 |
| 55-69 | B | 观察等待，或轻仓试水 |
| 40-54 | C | 不符合条件，观望 |
| <40 | D | 回避 |

## 评分使用建议

1. **S级标的**: 四层均≥20分，无明显短板
2. **A级标的**: 某一层稍弱但其他层强劲，需确认弱项是否可接受
3. **B级标的**: 仅适合特定策略（如高波动适合打板）
4. **一票否决项**: 监管立案/业绩暴雷/大股东大额减持 → 直接D级
