# A股量化交易系统 v3.1

> **版本**: v3.1-20260823 | **总代码量**: 13,988 行 | **核心模块**: 42 个
> **设计理念**: 融合20年专业交易经验 + 多层策略框架 + 多源数据融合

## 系统架构

```
用户接口层 (CLI/API)
    ↓
决策层 (策略类型判定 → 经典战法扫描 → 首启战法 → 仓位计算)
    ↓
评分引擎层 (四层框架评分 | 九维评分兼容 | 五维择时 | 特色因子)
    ↓
数据层 (腾讯实时 | iFinD增强 | Baostock历史 | FTShare财务 | Iwencai)
```

## 核心能力

### 一、四层框架评分（总分100）

| 维度 | 权重 | 核心指标 |
|:---|:---:|:---|
| 价值猎手 | 30分 | PE/PB分位、PEG、股息率、行业排名 |
| 财务透视 | 20分 | ROE、营收增长、毛利率、现金流质量 |
| 资金解码 | 25分 | 主力净流入、换手率、北向资金、大单比例 |
| 全维风控 | 25分 | 波动率、回撤、质押率、负债率、监管风险 |

### 二、七套经典战法

| 战法 | 类型 | 周期 | 核心逻辑 |
|:---|:---:|:---:|:---|
| 龙头首阴 | 打板 | 1-2天 | 连板龙头首阴+缩量低吸 |
| 龙回头 | 短线 | 5-15天 | 龙头回调15-30%二波启动 |
| 均线多头 | 趋势 | 10-30天 | 5>10>20>60多头排列回踩 |
| 箱体突破 | 突破 | 10-30天 | 横盘20-60天放量突破 |
| 量价齐升 | 动量 | 5-15天 | 价涨量增动量跟进 |
| 缩量回踩 | 震荡 | 5-15天 | 上涨回调量能萎缩 |
| 戴维斯双击 | 基本面 | 1-3月 | 业绩+估值双提升 |

### 三、策略类型判定（v3.1r新增）

```
输入: 个股代码 + 市场环境(bull/震荡/bear)
    ↓
消息面硬排除（监管函/业绩暴雷/大额减持 → 直接观望）
    ↓
过夜评分 (0-20分): 量能/筹码/消息/技术/流动性
波段评分 (0-15分): 趋势/基本面/资金/行业/催化
    ↓
输出: 过夜 / 波段 / 两者皆可 / 观望 + 建议仓位
```

### 四、五维择时

| 维度 | 指标 | 权重 |
|:---|:---|:---:|
| 估值 | 全市场PE/PB分位 | 20% |
| 资金 | 两融余额/北向/公募发行 | 25% |
| 技术 | 指数均线/成交量/MACD | 25% |
| 情绪 | 涨跌比/涨停数/炸板率/恐慌指数 | 20% |
| 基本面 | PMI/社融/利率/汇率 | 10% |

**输出**: bull（建议仓位70-80%）/ 震荡（50%）/ bear（30%以下）

### 五、凯利公式仓位管理

```
f* = (bp - q) / b  ×  趋势调整系数  ×  等级倍率

约束:
- 单票仓位 ≤ 20%
- 总仓位 ≤ 五维择时建议上限
- 现金比例 ≥ 30%
```

### 六、特色因子增强

- **BetaGap欠涨因子**: 行业涨但个股滞后，补涨潜力
- **筹码反转信号**: 筹码集中+价格触底反弹
- **日历效应**: 周一效应/节前效应/财报季效应

## 使用方式

### 1. 单票完整诊断

```bash
# 四层框架评分
python3 scripts/run_single_v3.py 000983

# 策略类型判定
python3 scripts/stock_screener.py classify 000983 bull

# 经典战法扫描
python3 scripts/stock_screener.py classic 000983

# 深度分析报告
python3 scripts/run_single_v3.py 000983 --deep
```

### 2. 批量选股

```bash
# 条件筛选（总分≥65）
python3 scripts/stock_screener.py filter '[{"field":"total_score","op":">=","value":65}]' AND

# 预设策略（动量/价值/成长/ dividend）
python3 scripts/stock_screener.py preset momentum

# 策略选股（均线多头/箱体突破等）
python3 scripts/stock_screener.py strategy ma_bull

# 排行（总分前20）
python3 scripts/stock_screener.py ranking total 20
```

### 3. 盘后定时更新

```bash
# 15:35执行：行情/K线/评分/排名全量更新
python3 scripts/daily_update_v3_1.py
```

### 4. Python API

```python
from scripts.stock_screener import StockScreener
from scripts.strategy_classifier import evaluate_stock
from scripts.classic_strategies import scan_all_strategies

screener = StockScreener()

# 策略判定
result = screener.classify('000983', market_env='bull')
# → {'strategy': {'type': '波段', 'position_pct': 0.25}}

# 经典战法扫描
signals = screener.classic_signals('000983')
# → [{'name': '箱体突破', 'entry': '突破6.91买入', 'stop_loss': '6.21'}]

# 批量筛选
results = screener.preset('momentum')
```

## 升级路线图（v3.2+）

1. **市场生态位识别**: 自动识别当前市场处于什么生态位（牛市初期/牛市中期/震荡市/熊市反弹/熊市主跌）
2. **资金行为分离**: 区分机构/游资/北向/散户资金流向，识别主导资金性质
3. **情绪周期判断**: 冰点→修复→高潮→退潮→冰点的完整周期定位
4. **产业链联动**: 上游→中游→下游的传导分析，识别轮动节奏
5. **事件驱动框架**: 政策/业绩/重组/涨价/技术突破等事件的影响力评估
6. **风险预算管理**: 基于VaR/CVaR的动态风险预算分配
7. **多时间框架验证**: 日线/周线/月线信号共振确认
